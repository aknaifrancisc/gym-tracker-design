# Gym Tracker Web — UI kit

Redesigned screens, all composed from the design system (soft `--wash-*` KPI widgets, bold `--grad-*` only on chips/heroes/PR cards, Hanken Grotesk + Spline Sans Mono, Lucide icons).

| File | Screen |
| --- | --- |
| `index.html` | Personal info / fitness profile |
| `dashboard.html` | Dashboard |
| `weight-loss.html` | Weight loss |
| `steps.html` | Activity & cardio |
| `workout-logs.html` | Workout logs |
| `exercises.html` | Exercise library |
| `macros-dashboard.html` | Macros dashboard |
| `daily-meals.html` | Daily meals |
| `recipes.html` | Recipes |
| `ingredients.html` | Ingredient library |

These are REDESIGN targets, not recreations — originals are the screenshots in `uploads/`.

Image areas on Exercises / Recipes / Ingredients are drag-and-drop `<image-slot>`s: drop the product's real photos in and they persist. No third-party imagery is bundled.
